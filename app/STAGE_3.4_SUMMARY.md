## 🎯 Результат

После выполнения этапа 3.4 каждая планета имеет:
- **strength_score** — числовое значение силы (от -20 до +50)
- **special_roles** — массив ролей (может быть пустым)

Пример:
```json
{
  "planet": "Pluto",
  "strength_score": 37.0,
  "special_roles": ["almuten"]
}
```
