```

- творческое начало
- запас жизненных сил
```

## Использование данных

### SQL запрос для получения функций планеты

```sql
SELECT planet, function_core, function_extended 
FROM ref_planet_psych_functions 
WHERE planet = 'Sun';
```

### Python код для получения функций

```python
from app.database.connection import get_db_session
from sqlalchemy import text

with get_db_session() as session:
    result = session.execute(
        text("SELECT function_core, function_extended FROM ref_planet_psych_functions WHERE planet = :planet"),
        {"planet": "Sun"}
    ).fetchone()
    
    if result:
        print(f"Основная функция: {result[0]}")
        print(f"Детальные функции:\n{result[1]}")
```
