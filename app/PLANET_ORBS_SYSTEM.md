# 🎯 Система индивидуальных орбисов планет

## Обзор

Реализована профессиональная система расчёта аспектов с **индивидуальными орбисами для каждой планеты**.

### Основное правило
> **"Если в аспекте участвуют планеты с разными орбисами - берём больший"**

---

## 📊 Структура данных

### Таблица `ref_planet_orbs`

```sql
CREATE TABLE ref_planet_orbs (
    planet VARCHAR(20) NOT NULL,
    aspect_type VARCHAR(30) NOT NULL,
    orb DECIMAL(5, 2) NOT NULL,
    PRIMARY KEY (planet, aspect_type)
);
```

**Содержит:**
- 21 планета/точка (Sun, Moon, Mercury, ..., ASC, MC, IC, DSC)
- 10 типов аспектов (после исключения 4 минорных)
- **210 записей** с индивидуальными орбисами

## 💡 Примеры расчёта

### Пример 1: Солнце ☉ - Луна ☽ (Соединение)
```
Орбис Солнца:  12.0°
Орбис Луны:    10.0°
Итоговый орбис: MAX(12.0, 10.0) = 12.0°
```

## 🚀 Использование в коде

### AspectService

```python
from app.services.aspect_service import AspectService

# Создать сервис
aspect_service = AspectService(db_session)

# Рассчитать аспекты (автоматически использует индивидуальные орбисы)
aspects = aspect_service.calculate_aspects(user_id)
```

### Внутренний алгоритм

```python
def _calculate_allowed_orb(self, body_a: str, body_b: str, aspect_type: str) -> float:
    """
    Получить орбисы для обоих тел
    Вернуть максимальный (правило: берём больший)
    """
    orb_a = get_orb_from_db(body_a, aspect_type)
    orb_b = get_orb_from_db(body_b, aspect_type)
    return max(orb_a, orb_b)
```

## ✅ Преимущества новой системы

1. **Астрологическая точность**: Светила имеют больший орбис влияния
2. **Гибкость**: Легко настроить орбисы для любой планеты
3. **Производительность**: Кэширование орбисов в памяти
4. **Совместимость**: Fallback на `base_orb` для неизвестных объектов
5. **Профессионализм**: Соответствует стандартам профессиональной астрологии
