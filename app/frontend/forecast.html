🔮 Прогностика

Прогностика — быстрый старт

⚡ Общий принцип

Задайте период (или быстрый пресет: 1 день / 1–12 мес) → нажмите «Рассчитать». На Biwheel сразу считаются и отображаются транзиты, прогрессии и дирекции. Переключайтесь между вкладками — данные сохраняются.

📊 Timeline (Ганнт)

Timeline показывает только транзитные события за выбранный период.

Каждая строка — уникальный аспект (напр. «♄ △ ☉»). Если аспект повторяется за период — на одной строке несколько баров. Яркость бара нарастает к моменту точного аспекта (●). Красная пунктирная линия — сегодня.

Строки отсортированы: медленные планеты (Плутон → Нептун → …) вверху, быстрые (Луна) внизу.

Наведение на бар → тултип с датами входа/точного/выхода, орбом и числом вхождений. Для дат вне выбранного периода ставится пометка «вне диапазона». Если вхождений несколько, показывается список всех повторов (#1, #2, ...).

Клик по бару → автопереход на Biwheel на дату точного аспекта.

Фильтр: переключатель «Мажорные» оставляет только мажорные аспекты.

⚡ Активные транзиты сейчас

Этот блок показывает только те аспекты, которые идут прямо сейчас: текущий момент попадает между входом в орбис и выходом из орбиса (t_enter ≤ сейчас ≤ t_leave).

Значок на карточке: точный через Nд — пик ещё впереди, сегодня! — точный аспект сегодня, точный Nд назад — пик уже прошёл, но аспект всё ещё действует в орбисе.

Важно: это не список «самых сильных» и не прогноз на весь период, а моментальный срез активных влияний на текущую дату/время.

🎯 Biwheel

Двойное колесо: натал (внутри) + прогностические позиции (снаружи). На выбранную дату одновременно показываются транзиты, прогрессии и дирекции.

Легенда под картой работает как фильтр слоёв: можно включать/выключать Натал, Транзиты, Прогрессии, Дирекции. У пункта «Дирекции» есть выпадающий список типа: солнечная дуга / символические / Найбод.

Левые и правые таблицы на Biwheel можно свернуть кнопкой в шапке таблицы. Обратно открыть — маленькими кнопками на краях карты.

Масштаб: колесо мыши или кнопки +/− в правом нижнем углу. Панорама: зажмите и перетащите. Кнопка ⟳ — сброс вида. На тач-экранах — pinch для zoom.

📋 Таблица

Нижняя вкладка «Таблица» показывает общую выборку аспектов по периоду (транзиты + прогрессии + дирекции) и отдельно блок ингрессий. Клик по заголовку столбца — сортировка, повторный клик меняет направление.

☀️ Соляр

Солнечное возвращение на выбранный год. Показывает карту соляра с позициями планет и домов.

💡 Советы

  • Для быстрого просмотра текущей динамики используйте пресет «1 день»
  • Для стратегического обзора периода начните с 6 месяцев на Timeline
  • На Biwheel выключайте лишние слои легендой, чтобы не перегружать карту
  • В нижней таблице отсортируйте по орбу, чтобы увидеть самые точные аспекты сверху
