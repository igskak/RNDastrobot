🔮 Прогностика

Прогностика — быстрый старт

⚡ Общий принцип

Выберите метод → задайте период/дату → нажмите «Рассчитать». Результат отобразится на активной вкладке. Переключайтесь между вкладками — данные сохраняются.

📊 Timeline (Ганнт)

Каждая строка — уникальный аспект (напр. «♄ △ ☉»). Если аспект повторяется за период — на одной строке несколько баров. Яркость бара нарастает к моменту точного аспекта (●). Красная пунктирная линия — сегодня.

Строки отсортированы: медленные планеты (Плутон → Нептун → …) вверху, быстрые (Луна) внизу.

Над таймлайном — сводка активных транзитов на текущую дату.

Наведение на бар → тултип с датами входа/точного/выхода и числом вхождений.

Клик по бару → автопереход на Biwheel на дату точного аспекта.

Фильтры: Мажорные/минорные, без Луны, группы планет (Внешние, Внутренние, Узлы/Точки).

🎯 Biwheel

Двойное колесо: натал (внутри) + прогностические позиции (снаружи). Справа — скроллируемый список аспектов. Работает для всех методов: транзиты, прогрессии, дирекции.

Масштаб: колесо мыши или кнопки +/− в правом нижнем углу. Панорама: зажмите и перетащите. Кнопка ⟳ — сброс вида. На тач-экранах — pinch для zoom.

📋 Таблица

Все аспекты в табличном виде. Клик по заголовку столбца — сортировка (дата, метод, транзитная планета, аспект, натальная планета, орб, тип). Повторный клик — обратный порядок.

☀️ Соляр

Солнечное возвращение на выбранный год. Показывает карту соляра с позициями планет и домов.

🔧 Методы

ТранзитыРеальные позиции планет за период. Используйте пресеты дат (1–12 мес) для быстрого выбора.
ПрогрессииВторичные прогрессии (день = год). Задаётся конкретная дата.
ДирекцииСолнечная дуга, символические (1°/год), экваториальные (Найбод). Задаётся дата.

💡 Советы

  • Начните с транзитов на 6 мес — увидите общую картину на Timeline
  • Кликните интересный транзит → Biwheel покажет карту на эту дату
  • Отключите внутренние планеты, чтобы сфокусироваться на медленных транзитах
  • В таблице отсортируйте по орбу — точные аспекты будут сверху
