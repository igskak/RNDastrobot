# skill_prd

## Purpose
Create a concise PRD before implementation.

## Inputs
- Feature request and business goal.
- Current constraints (time, scope, stack).
- Existing behavior and pain points.

## Outputs
- PRD with: goal, non-goals, user stories, risks, open questions.

## Procedure
1. Restate feature in one sentence.
2. Define measurable goal and explicit non-goals.
3. Capture user stories (`As a ... I want ... so that ...`).
4. List risks (tech/product/ops) and mitigation.
5. List open questions and decisions needed before coding.
6. End with acceptance signals for kickoff.

## How To Invoke In Codex App
`Используй docs/codex/skill_prd.md и подготовь PRD для фичи: <описание>.`
