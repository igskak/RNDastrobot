# Специальные астрологические точки

## Краткая справка по расчётам

### Лилит (Чёрная Луна) 🌑

**Метод:** Mean Apogee (Средний апогей Луны)

```python
from app.services.special_points_service import SpecialPointsService

jd = 2448145.777083333  # Юлианский день
lilith = SpecialPointsService.calculate_black_moon(jd)
# Результат: 244.771261° (Стрелец 4°46')
```

**Почему этот метод?**
- ✅ Стандарт в астрологии (Swiss Ephemeris: "most astrologers use Mean Apogee")
- ✅ Используется в ZET и большинстве программ
- ✅ Точность: < 0.3' от данных астрологов

---

### Селена (Белая Луна) 🌕

**Метод:** Формула ZET (период 7.0 лет)

```python
from app.services.special_points_service import SpecialPointsService

jd = 2448145.777083333  # Юлианский день
selena = SpecialPointsService.calculate_white_moon(jd)
# Результат: 123.866667° (Лев 3°52')
```

**Формула:**
```
Селена = (242.49 + 0.1408 × (JD - 2451545.0)) mod 360
```

**Почему этот метод?**
- ✅ Точное совпадение с ZET (0.00" разницы)
- ✅ Используется в русскоязычной астрологии
- ✅ Авестийская традиция

## Важные замечания

⚠️ **Не изменяйте формулы без веской причины!**

Текущие методы обеспечивают:
1. Совместимость с ZET (самая популярная программа в СНГ)
