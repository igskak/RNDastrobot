# Методы расчёта Лилит и Селены

## Обзор

Данный документ описывает методы расчёта Чёрной Луны (Лилит) и Белой Луны (Селены), используемые в проекте, и обоснование выбора этих методов.

---

## Лилит (Чёрная Луна)

### Выбранный метод: **Mean Apogee (Средний апогей)**

#### Реализация
```python
black_moon_data, ret = swe.calc_ut(jd, swe.MEAN_APOG, swe.FLG_SWIEPH)
```

#### Обоснование выбора

1. **Стандарт в астрологии**
   - Документация Swiss Ephemeris прямо указывает: *"most astrologers associate her with the Mean Apogee"*
   - Используется в большинстве астрологических программ по умолчанию
   - Публикуется в стандартных астрологических эфемеридах

2. **Совместимость с ZET**
   - Программа ZET (Zet Geo), широко используемая астрологами, использует именно этот метод
   - Точность совпадения: < 0.3 угловых минут

3. **Стабильность**
   - Средний апогей движется плавно и предсказуемо
   - В отличие от осциллирующего апогея, который колеблется на ±30° вокруг среднего значения

#### Альтернативные методы (не используются)

- **True/Osculating Apogee** (`swe.OSCU_APOG`) - истинный/осциллирующий апогей
  - Используется реже
  - Сильные колебания (±25-30°)
  - Не является стандартом

- **Interpolated Apogee** (`swe.INTP_APOG`) - интерполированный апогей
  - Используется очень редко
  - Сглаженная версия осциллирующего апогея

## Селена (Белая Луна)

### Выбранный метод: **Формула ZET**

#### Реализация
```python
J2000 = 2451545.0  # Эпоха J2000.0 (1 января 2000, 12:00 TT)
INITIAL_LONGITUDE = 242.4900166227  # Начальная долгота на J2000
MEAN_MOTION_PER_DAY = 0.1408037548  # Среднее движение в градусах/день

days_from_j2000 = jd - J2000
selena_longitude = (INITIAL_LONGITUDE + MEAN_MOTION_PER_DAY * days_from_j2000) % 360
```

#### Параметры формулы

- **Период обращения:** 7.0 лет (ровно)
- **Начальная долгота на J2000.0:** 242.4900166227°
- **Среднее движение:** 0.1408037548 град/день

#### Обоснование выбора

1. **Совместимость с ZET**
   - Точное совпадение с программой ZET
   - Разница: 0.00 угловых секунд

2. **Распространённость в русскоязычной астрологии**
   - Широко используется в русскоязычной астрологической школе
   - Применяется в авестийской астрологической традиции

3. **Отсутствие единого стандарта**
   - Селена - гипотетическое тело без физического существования
   - Разные астрологические школы используют разные формулы
   - Swiss Ephemeris признаёт: *"Selena/White Moon. This is a 'hypothetical' second Moon of the Earth... of obscure provenance"*

#### Альтернативные методы (не используются)

- **Swiss Ephemeris Fictitious Body #17**
  - Период: 7.022 года
  - Начальная долгота: 242.22°
  - Расхождение с ZET: ~20 угловых минут
  - Используется в некоторых западных программах

- **Формула "Лилит + 180°"**
  - Самый простой метод
  - Не используется серьёзными астрологами
  - ❌ Не рекомендуется
