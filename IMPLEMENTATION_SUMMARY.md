### 2. Обновлён метод расчёта Селены (Белая Луна)

**Файл:** `app/services/special_points_service.py`

**Изменения:**
- Заменена формула "Лилит + 180°" на формулу ZET
- Реализован расчёт по формуле с периодом 7.0 лет

**Формула ZET:**
```
Селена = (242.4900166227 + 0.1408037548 × (JD - 2451545.0)) mod 360
```

**Параметры:**
- Период обращения: 7.0 лет (ровно)
- Начальная долгота на J2000.0: 242.4900166227°
- Среднее движение: 0.1408037548 град/день

**Обоснование:**
- Точное совпадение с программой ZET
- Широко используется в русскоязычной астрологии
- Авестийская астрологическая традиция

**Результат:**
- ✅ Точность: 0.00" (абсолютное совпадение с ZET)
